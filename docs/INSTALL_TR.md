# Installation by version

This development branch is **Pro 1.5**, which requires both ESP firmware and FAP.
Use [Pro 1.5 installation](PRO_1_5_TR.md). Do not apply the old FAP-only update
instruction to this branch.

For the stable 1.0 build, use the immutable
[v1.0.0 installation guide](https://github.com/sehmusadsoy-ui/flipper-csi/blob/v1.0.0/docs/INSTALL_TR.md)
and its matching release assets.
