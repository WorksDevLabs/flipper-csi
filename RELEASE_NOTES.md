# CSI Radar Pro 1.5 — device-test candidate

This is a development checkpoint for the planned v1.5.0 release. Do not publish
a stable tag until the physical and real-capture gates in ROADMAP.md pass.

Includes Wi-Fi scan/select, masked password entry, bilingual help, persistent
profiles/settings, explicit auto/manual thresholds, calibration rejection,
handshake/recovery, queued SD logging and offline RAW diagnostics.

Upgrade ESP firmware and FAP together. E11 system firmware stays installed.
See docs/PRO_1_5_TR.md. Existing v1.0.0 assets and tag remain unchanged.
No range, direction, stationary occupancy or vital-sign measurement is added.
